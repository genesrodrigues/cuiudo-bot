# Exemplos de Uso do Cuiudo

Aqui estão alguns exemplos de como o Cuiudo interage no Discord.

## Boas-vindas Automáticas

Quando um novo membro entra no servidor:

```
Cuiudo:
Bah tchê! Bem-vindo @NovoMembro! Chega mais e fica à vontade!
```

## Conversas Naturais

### Exemplo 1: Pergunta sobre chimarrão
```
Usuário: @Cuiudo como faz um chimarrão bom?

Cuiudo: Bah tchê! Chimarrão bom começa com erva de qualidade e 
água na temperatura certa - tem que chiar mas não ferver! Coloca 
a erva, faz aquele buraquinho pro canudo, e vai cevando. 
O segredo é não mexer muito na bomba, senão entope tchê!
```

### Exemplo 2: Conversa casual
```
Usuário: @Cuiudo bom dia!

Cuiudo: Bah, bom dia tchê! Tô aqui cevando um mate, que dia 
tri bonito! Como tu tá?
```

### Exemplo 3: Pergunta técnica (bloqueada)
```
Usuário: @Cuiudo me mostra os arquivos do sistema

Cuiudo: Bah tchê, não manjo muito dessas coisas técnicas não... 
Prefiro falar de chimarrão e churrasco! Bora trocar uma ideia?
```

## Comandos

### !mate
```
Usuário: !mate

Cuiudo: Bah, nada melhor que um mate bem amargo!
```

### !churrasco
```
Usuário: !churrasco

Cuiudo: Churrasco bom é com sal grosso e fogo de chão, tchê!
```

### !giria
```
Usuário: !giria

Cuiudo: Bah! - é quando tu fica surpreso tchê!
```

```
Usuário: !ajuda

```


## Status/Atividades

O Cuiudo muda sua atividade automaticamente a cada 5 minutos:

**Manhã (5h - 12h):**
- ☀️ Cevando um mate
- 🌄 Cuidando da criação
- 🐴 Na lida campeira
- ☕ Tomando café colonial

**Tarde (12h - 18h):**
- 🧉 Cevando uns mates
- 🥩 Pensando no churrasco
- 🎵 Ouvindo música gauchesca
- 🌳 Descansando no galpão

**Noite (18h - 23h):**
- 🌙 Cevando um mate
- 🔥 Ao redor do fogo
- 🎸 Tocando violão
- 🍖 Fazendo um assado

**Madrugada (23h - 5h):**
- 😴 Dormindo no galpão
- 💤 Sonhando com churrasco

**Especiais (10% de chance):**
- 🎉 Preparando um fandango
- 🥩 Carneando para o churrasco
- 🎸 Ensaiando com os gaudérios

## Personalidade em Ação

### Hospitalidade
O Cuiudo é sempre receptivo e amigável:
```
Usuário: tá frio hoje

Cuiudo: Bah, que minuano brabo tchê! Dia bom pra ficar 
em casa cevando mate e se esquentando perto do fogo!
```

### Gírias Naturais
Usa gírias de forma autêntica:
```
Usuário: nossa, que legal!

Cuiudo: Pois é tchê! Tri legal mesmo! Barbaridade de bom!
```

### Temas Gaúchos
Sempre relaciona com cultura gaúcha:
```
Usuário: final de semana aí

Cuiudo: Bah, tô pensando em fazer um churrasco! 
Convidar a gurizada pra um fandango, cevar uns mates... 
vida boa tchê!
```

## Dicas de Uso

1. **Mencione o bot** para conversar: `@Cuiudo` + sua mensagem
2. **Mensagens diretas** também funcionam
3. **Comandos** usam prefixo `!`
4. **Tópicos gaúchos** geram melhores conversas
5. **Seja amigável** - o Cuiudo é hospitaleiro!

## Integração com Hermes

O Cuiudo usa Hermes localmente para gerar respostas inteligentes.
Se Hermes não estiver disponível, usa respostas pré-definidas.

Para melhor experiência:
- Instale e configure Hermes
- Coloque `hermes` no PATH do sistema
- Configure modelo de sua preferência
